# 自動備份（Google Apps Script）

跑在 Google 伺服器上，**不需要 MacBook 開機**。以你的帳號身分執行，因此有儲存空間配額——這是服務帳號做不到、本機腳本必須存在的原因。

## 安裝（約 5 分鐘，只需做一次）

1. 用 `alan.z@hiyes.tw` 登入，開啟 <https://script.google.com>
2. 左上「**新專案**」，把專案命名為「婚禮相簿備份」
3. 刪掉編輯器裡預設的程式碼，貼上 `backup.gs` 的全部內容
4. 按 💾 儲存
5. 上方函式選單選 **`backupAll`** → 按 **執行**
   - 第一次會跳授權：選你的帳號 → 「進階」→「前往 婚禮相簿備份（不安全）」→ 允許
   - 這是因為指令碼未經 Google 審核，是你自己寫的所以安全
6. 執行完畢後，函式選單改選 **`setupHourlyTrigger`** → 按 **執行**
   - 這會建立每小時自動備份的排程

完成。之後每小時自動備份，MacBook 關機也照跑。

## 確認有在運作

- 左側「**執行項目**」可看每次執行的紀錄與結果
- 或直接開 [備份相本](https://drive.google.com/drive/folders/1IJsox9j7uMzKqWiZFRuJ2R24FfjqXerT) 看檔案數量

## 備份內容

```
備份相本/
├── photos/              所有賓客照片
├── videos/              所有賓客影片
└── 祝福文字備份.txt      含時間、名稱，連隱藏/刪除的也保留
```

- 以「檔名 + 大小」判斷是否已備份，重複執行不會重複複製
- 單次執行上限 6 分鐘，接近時會停手，下一次排程接著做

## 婚禮當天

不用管它。照片一上傳就已經在共用雲端硬碟，這個排程每小時再複製一份到你的個人雲端硬碟。

婚禮結束後想立刻備份，到 script.google.com 手動按一次 `backupAll` 即可。

## 與本機腳本的關係

`scripts/backup.mjs` 仍可用，作為手動或離線時的備援：

```bash
node scripts/backup.mjs status   # 看還有幾個沒備份
node scripts/backup.mjs          # 手動備份
```

兩者寫入同一個資料夾、用同樣的去重規則，同時存在不會互相干擾。
